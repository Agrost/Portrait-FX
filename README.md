# Sano’s Portrait FX — 1.8.2

## Необязательные зависимости

Foundry 13–14. Обычные портреты работают без FXMaster, FXMaster+ и TokenMagic.
Для эффектов нужны включённые FXMaster 8.3.6+ и FXMaster+ 1.1.14+ с поддержкой эффектов в просмотрщике.
Более новая версия FXMaster+ может требовать более новую версию FXMaster.
Без подходящего движка эффекты недоступны, но их настройки сохраняются в мире.
Для возвращения эффектов включи зависимости и перезагрузи мир.
TokenMagic также необязателен и использует движок FXMaster+; выбирай его версию под свой Foundry.
TokenMagic 0.8.4 требует Foundry 14; старые версии TokenMagic в Foundry 13 отдельно не проверены.

## Неочевидные действия

- **ПКМ по персонажу в любом из двух списков меню** — убрать портрет. Сам персонаж в мире остаётся.
- **Двойной клик по имени добавленного портрета в меню** — скрыть или показать его игрокам.
- **Двойной клик по портрету на экране** — открыть его настройки у GM.
- **Двойной клик по заголовку меню** — свернуть или развернуть окно; **по нижнему правому углу** — вернуть стандартный размер.
- **Перетаскивание заголовка** перемещает меню; **нижнего правого угла** меняет размер; **портрета** меняет положение по горизонтали.
- **Alt+P** — открыть или закрыть меню GM; у игрока — раскрыть или свернуть нижнюю панель.
- **Стрелки в поиске и списке** выбирают строку; **Enter / пробел на строке** добавляет персонажа; **Escape** возвращает к поиску.
- Повторный клик **«Изменить имя»** закрывает форму и отменяет несохранённый ввод. **«Изображение и размер»** открывает и закрывает форму без потери введённых в ней значений до применения.

## Добавление и показ

- Найди персонажа по части имени и нажми его имя или картинку. Перед добавлением выбери **имя**, **скрытие** и **высоту** (100–700 px, по умолчанию 500).
- **Звезда** переключает избранное, не добавляя портрет. Избранные идут первыми после повторного открытия меню.
- Повторное добавление показывает существующий портрет с выбранными высотой и настройкой имени, без дубликата.
- Выбери добавленный портрет для настройки. **«Показать / Скрыть»** управляет им; **«Показать все / Скрыть все»** — всем списком.

**Подготовка только для GM:** скрой портрет → включи **«Предпросмотр GM»** → настрой внешний вид и эффекты → нажми **«Показать»**. До этого портрет виден только тебе. Предпросмотр работает для одного скрытого портрета и сбрасывается после показа или перезагрузки. Изменения уже показанного портрета сразу видят игроки.

## Настройка портрета

- **«Изменить имя»** меняет подпись, а не имя персонажа в мире. Подтверди кнопкой **«Сохранить имя»** или Enter. **«Показать / Скрыть имя»** управляет подписью.
- **«Изображение и размер»** открывает путь к картинке, высоту и положение. Для сохранения нажми **«Применить»**. Поддерживаются PNG, WebP и JPEG, включая прозрачность.
- **↔** отражает изображение; **← / →** меняют его местами с соседом. **«Распределить равномерно»** сбрасывает ручные позиции показанных портретов. **«Снизу»** задаёт общий отступ.

## Эффекты

- Выбери **Filter Effects**, **Particle Effects** или **TokenMagic**, затем эффект. Нажми **«Включить эффект»** или измени параметр — изменения применяются автоматически. Можно включить несколько эффектов; их названия открывают настройки.
- Для копирования TokenMagic выдели **ровно один токен** и нажми **«Взять эффекты выбранного токена»**. Сохраняется отдельная копия; последующие изменения токена не переносятся.
- **TokenMagic → «Добавить макрос»**: введи название, вставь JavaScript-код применения фильтров и нажми **«Сохранить макрос»**. Эффект появится в списке у всех портретов и сохранится в этом мире. Нажми **«Включить эффект»** для запуска; выключение и повторное включение начинают анимацию заново. Добавлять макросы может GM; токен для импорта не нужен.
- **«Применить эффект ко всем»** включает выбранный эффект с текущими параметрами у всех портретов, включая скрытые.
- **«Стандартные настройки»** сбрасывают параметры эффекта. Кнопки снятия эффектов отключают их у одного персонажа или у всех, сохраняя оформление и параметры.

Water отключён для портретов. Поддержка TokenMagic экспериментальная; анимации переносятся из пресета или токена, отдельного редактора анимаций нет.

### Задержка анимации в макросе

Импорт сохраняет параметры фильтров; вызовы `setTimeout` после завершения макроса не переносятся.
Для задержки добавь `delay` в нужный параметр `animated`. Например, прозрачность останется равной 1
первые 50 секунд, затем плавно снизится до 0 за 20 секунд:

```js
alpha: 1,
animated: {
  alpha: {
    active: true, animType: "halfCosOscillation",
    val1: 1, val2: 0, loops: 1,
    loopDuration: 20000, delay: 50000
  }
}
```

`delay` задаётся в миллисекундах и относится только к выбранному параметру. Остальные анимации
продолжают работать. Повторное включение эффекта запускает задержку заново. При отключённых
анимациях TokenMagic задержка также приостанавливается. Это расширение для портретов, оно не меняет TokenMagic на сцене.
Уже импортированный макрос с таймером нужно заменить новым импортом с `delay`.

## У игрока

Наведи курсор на нижнюю полоску **«Портреты»**. Здесь можно скрыть портреты, перевернуть выбранный и сбросить положения. Эти действия и перетаскивание портрета влияют только на твой экран и сохраняются в этом браузере. **«Сбросить положение»** возвращает координаты GM. Показать скрытый GM портрет нельзя.

## Установка и обновление

1. На стартовом экране Foundry открой **Add-on Modules → Install Module**, вставь ссылку ниже в **Manifest URL** и нажми **Install**:

   ```text
   https://github.com/Agrost/Portrait-FX/releases/latest/download/module.json
   ```

   Обновления устанавливаются через **Update** в списке модулей. Для ручной установки помести папку `sanos-portrait-fx` из релизного ZIP в `Data/modules`, перезапусти Foundry и включи модуль в мире.
2. Включи **Sano’s Portrait FX**. Для обычных портретов другие модули не нужны. Для эффектов дополнительно включи совместимые **FXMaster** и **FXMaster+**; для TokenMagic — совместимый **Token Magic FX** и **libWrapper**.
3. Открой меню через кнопку **Sano’s Portrait FX** в инструментах токенов или **Alt+P**.

Общие настройки сохраняются в мире, избранное и личные настройки — у пользователя. Заявлена совместимость с Foundry 13–14; работа в настоящем Foundry пока не проверена.
