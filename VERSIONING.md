# Версионирование FX Portraits

Этот Git-репозиторий содержит только FX Portraits: исходники, стили,
документацию и тесты. FXMaster, FXMaster+ и TokenMagic находятся вне репозитория.

## Публикация исходников

Удалённый репозиторий: https://github.com/Agrost/Portrait-FX, основная ветка — `main`.
Обновление исходников коммитом не создаёт установочный релиз Foundry.
Для установочного релиза отдельно меняются согласованный номер версии, ссылка
на архив и тег, затем публикуются `module.json` и ZIP.

Ниже описана отдельная первоначальная локальная история разработки. Её теги,
ветки и резервный bundle не обязательно доступны в GitHub.

## Исходная точка локальной истории

- Ветка `main`: исходная версия до добавления TokenMagic.
- Тег `v1.3.0`: точка возврата к этой версии.
- На 7 октября 2026 года все 15 файлов релиза побайтово совпадают с
  соседним архивом `fx-portraits-1.3.0.zip`.
- Повторная проверка: 78 автоматических тестов прошли, ошибок нет.
  Работа в настоящем Foundry в этом проходе не проверялась.

Перед реализацией TokenMagic создаётся отдельная ветка `feature/tokenmagic`.
Изменения сохраняются небольшими коммитами; точка `v1.3.0` не перемещается.

## Возврат к исходной версии

Сначала сохранить текущую работу коммитом в её ветке. Затем при чистом рабочем
дереве создать отдельную ветку из исходного тега:

```powershell
git switch -c rollback/v1.3.0 v1.3.0
```

Это сохраняет историю новой реализации в прежней ветке. Для её продолжения:

```powershell
git switch feature/tokenmagic
```

Последняя команда применима после создания ветки реализации.
Для повторных возвратов использовать новое имя ветки возврата.

Возврат Git меняет только файлы этой папки. Если модуль установлен в другой
папке Foundry, нужно также заменить там файлы модуля исходным релизом и
перезапустить Foundry. Git не сохраняет настройки мира и документы Actor:
перед изменениями формата сохранённых данных нужна отдельная резервная копия мира.

## Отдельная копия истории

Рядом с папкой модуля создан `fx-portraits-baseline-v1.3.0.bundle` — снимок
исходной истории Git. Он не обновляется автоматически и содержит только
исходную точку. Восстановить её в новую папку можно командой:

```powershell
git clone --branch main ../fx-portraits-baseline-v1.3.0.bundle ../fx-portraits-restored
```

Для этой первоначальной локальной истории удалённый сервер не настраивался.
